# KNIGHT

> Official Discord bot for the NIZOLAX community.

KNIGHT is a Discord.js v14 bot built with TypeScript. This repository contains the source code of the bot used in the official community and is **not intended to be used as a public template**.

## Features

* Modular command handler
* Modular event handler
* TypeScript + ESM
* Canvas image generation
* Moderation system
* Utility commands

## Installation

```bash
git clone https://github.com/NickHubDev/KNIGHT.git
cd KNIGHT
npm install
```

Create a `.env` file with your Discord credentials and run:

```bash
npm run dev
```
