# Contributing to KNIGHT

Thank you for wanting to improve KNIGHT.

This repository is the official source code of the bot and **is not a template project**.

## Before contributing

* Create a feature branch.
* Keep the existing project architecture.
* Use TypeScript.
* Test your changes before opening a Pull Request.

## Code style

* One feature per Pull Request.
* Keep commands inside `src/commands`.
* Keep events inside `src/events`.
* Export every module using `export default`.

## Ownership

By submitting a Pull Request, you agree that your contribution becomes part of the KNIGHT project and may be modified or maintained by the repository owner.

Contributors will always remain credited through the Git history of the project.
